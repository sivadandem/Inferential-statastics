Measures of Central Tendency
One number to represent the whole dataset
➗ Mean (Average) MOST USED
Definition

The sum of all values divided by how many values there are — the "balance point" of the data.

Mean (μ or x̄) = (Σ x) ÷ n
Where / When Used

Any numeric column that is roughly symmetric with no extreme outliers. Used constantly as the default summary statistic and as an input to variance, standardization, and many ML models.

🚢
Mean Age = 29.7 years — the "typical" passenger if everyone were averaged out.
⚠️
Weakness: heavily pulled by outliers. A few Fares of 500+ push mean Fare to 32.2, well above what most people actually paid.
python df['Age'].mean() # 29.7 df['Fare'].mean() # 32.2 — pulled up by expensive tickets
🎯 Median (Middle Value) ROBUST
Definition

The middle value once data is sorted — half the values fall below it, half above.

Odd n → the middle value  |  Even n → average of the two middle values
Where / When Used

Skewed data: income, salary, house prices, fares — anywhere a few extreme values would distort the mean.

🚢
Median Fare = 14.45 — far below mean Fare (32.2). That gap alone is your first sign of skewness.
✅
Strength: not affected by extreme outliers. Always check median alongside mean.
python df['Age'].median() # 28.0 df['Fare'].median() # 14.45
🔁 Mode (Most Frequent Value) FOR CATEGORIES
Definition

The value that appears most often. The only central-tendency measure that also works on categorical data.

Where / When Used

Categorical columns (Sex, Embarked, Pclass-as-category), and filling missing categorical values.

🚢
Mode of Pclass = 3 (most passengers travelled 3rd class). Mode of Embarked = S (Southampton).
python df['Pclass'].mode()[0] # 3 df['Embarked'].mode()[0] # 'S'
⚖️ Mean vs Median vs Mode — When to Trust Which CRITICAL
SituationBest MeasureWhy
Symmetric, no outliersMeanUses every value, most precise
Skewed / outliers presentMedianIgnores extreme values
Categorical dataModeMean/median don't apply to categories
Income, price, real-estateMedianAlmost always right-skewed
🧠
Skew diagnostic: Mean ≈ Median ≈ Mode → symmetric. Mean > Median → right-skewed (like Fare). Mean < Median → left-skewed.

Measures of Dispersion (Spread)
Two datasets can share a mean and look completely different
🎯
Why this matters: Class A scores 50,50,50,50,50 (mean=50). Class B scores 0,25,50,75,100 (mean=50). Same mean, totally different spread.
↔️ Range SIMPLEST
Definition

The distance between the largest and smallest value.

Range = Max − Min
Where Used

A quick, rough first impression of spread.

🚢
Age range = 80 − 0.42 = 79.58 years
⚠️
Only uses 2 values — extremely sensitive to a single outlier.
python df['Age'].max() - df['Age'].min() # 79.58
📐 Variance FOUNDATION
Definition

The average of the squared distances of each point from the mean. Squaring removes negative signs and punishes larger deviations more.

Population: σ² = Σ(x − μ)² ÷ n   |   Sample: s² = Σ(x − x̄)² ÷ (n−1)
Where Used

Mathematical foundation for std dev, ANOVA, and many models. Rarely reported on its own because its unit is squared.

🧠
Why n−1 for samples? "Bessel's correction" — gives an unbiased estimate of the population variance from a sample. Pandas uses n−1 by default (ddof=1).
python df['Age'].var() # ≈ 211.0 (sample variance, ddof=1)
📊 Standard Deviation MOST USED
Definition

The square root of variance — brings the units back to the original scale (years instead of years²). This is why it's reported far more than variance.

σ (or s) = √Variance
Where Used

Reporting spread, the empirical (68-95-99.7) rule, z-scores, confidence intervals — anywhere "how spread out" needs a real-world unit.

🚢
Std Dev of Age ≈ 13.0 years — most ages fall within ~13 years of the mean (29.7). Std Dev of Fare ≈ 49.7 — huge relative to mean Fare (32.2), confirming heavy skew.
python df['Age'].std() # ≈ 13.0 df['Fare'].std() # ≈ 49.7
📦 Interquartile Range (IQR) ROBUST
Definition

The spread of the middle 50% of the data. Unaffected by extreme outliers.

IQR = Q3 (75th percentile) − Q1 (25th percentile)
Where Used

The go-to spread measure for skewed data; also the basis of the IQR outlier rule and boxplots.

python Q1 = df['Fare'].quantile(0.25) # 7.91 Q3 = df['Fare'].quantile(0.75) # 31.00 IQR = Q3 - Q1 # 23.09
📈 Coefficient of Variation (CV) GOOD TO KNOW
Definition

Standard deviation expressed as a % of the mean — lets you compare spread across variables with different units or scales.

CV = (Std Dev ÷ Mean) × 100
Where Used

Comparing "how spread out" two differently-scaled columns are (e.g. Age in years vs Fare in currency).

🚢
CV(Age) = 13.0 ÷ 29.7 × 100 = 43.8%  |  CV(Fare) = 49.7 ÷ 32.2 × 100 = 154.3%. Fare is relatively much more spread out than Age.

Shape of the Distribution
Skewness and kurtosis — the "fingerprint" of a column's shape
📐 Skewness MUST KNOW
Definition

Measures the asymmetry of a distribution — which side has the longer tail.

When
  • Any continuous variable
  • Before choosing mean vs median
  • Before picking a statistical test
Where (DA)
  • Age, Fare, Income, Price columns
  • Any column with a long tail
Why
  • Decides parametric vs non-parametric tests
  • Flags where mean is misleading
How to Identify
  • Histogram shape
  • df.skew()
  • Mean vs Median gap
SkewnessShapeTail DirectionMean vs Median
-0.5 to +0.5Approximately symmetricNoneMean ≈ Median
+0.5 to +1Moderately right-skewedLong tail rightMean > Median
> +1Highly right-skewedLong tail rightMean ≫ Median
-1 to -0.5Moderately left-skewedLong tail leftMean < Median
< -1Highly left-skewedLong tail leftMean ≪ Median
🚢
Age skewness ≈ 0.39 → approximately symmetric. Fare skewness ≈ 4.78 → strongly right-skewed (a handful of very expensive tickets pull the tail out).
python df['Age'].skew() # ≈ 0.39 df['Fare'].skew() # ≈ 4.78 → strong right skew
⛰️ Kurtosis IMPORTANT
Definition

Measures how peaked or flat a distribution is, and how heavy its tails are, versus a normal distribution.

Excess Kurtosis = Kurtosis − 3  (pandas/scipy report excess kurtosis by default)
Excess KurtosisTypeMeaning
≈ 0MesokurticNormal-like tails
> 0LeptokurticSharper peak, fatter tails, more outliers
< 0PlatykurticFlatter peak, thinner tails, fewer outliers
python df['Fare'].kurt() # ≈ 33.4 → extremely leptokurtic (heavy outlier tail)
🧠
Skewness vs Kurtosis: skewness tells you which side is longer; kurtosis tells you how extreme the tails/outliers are. Check both together.
📏
Thumb rule: higher kurtosis → more outliers expected.
🗂️ Frequency Distributions FOUNDATION
Definition

A table (or chart) showing how often each value or range of values occurs — the raw material behind every histogram.

Where Used

Summarizing categorical columns, binning numeric columns to inspect their shape before deciding on mean/median or a statistical test.

python # Categorical frequency table df['Pclass'].value_counts() # Numerical → binned frequency table pd.cut(df['Age'], bins=5).value_counts().sort_index() # As relative frequency (%) df['Pclass'].value_counts(normalize=True) * 100

📍 Z-Score (Standardized Value) CONNECTS TO NORMAL DIST
Definition

How many standard deviations a value is from the mean. Turns any value into a comparable, unit-free number.

z = (x − mean) ÷ std dev
Z ScoreMeaning
0Exactly the mean
±1Normal observation
±2Slightly unusual
±3Very rare observation
> +3 or < -3Possible outlier
🚢
A passenger aged 68: z = (68 − 29.7) ÷ 13.0 ≈ 2.95 → almost 3 std devs above average age.
📌
Important: a z-score does NOT remove outliers — it only flags unusual observations. Deciding to remove is a separate step (see Decision Trees).
python df['age_zscore'] = (df['Age'] - df['Age'].mean()) / df['Age'].std()

Covariance & Correlation (Descriptive)
Do two variables move together — and how strongly?
🔗 Covariance FOUNDATION
Definition

Measures the direction two variables move together — positive means they rise together, negative means one rises as the other falls.

Cov(X,Y) = Σ[(x − x̄)(y − ȳ)] ÷ (n − 1)
⚠️
Covariance's scale depends on the units of X and Y, so it can't tell you how strong the relationship is — only correlation (standardized) can.
python df[['Age','Fare']].cov()
📉 Correlation Coefficient STANDARDIZED
Definition

Covariance rescaled to always fall between -1 and +1, comparable across any pair of variables. This is a purely descriptive number — whether it's statistically significant is tested in the Inferential tab.

r = Cov(X,Y) ÷ (σx × σy)
|r| valueStrength
0.90 – 1.00Very strong
0.70 – 0.90Strong
0.40 – 0.70Moderate
0.20 – 0.40Weak
0.00 – 0.20Negligible
🚢
Correlation of Fare & Survived ≈ 0.26 → weak-to-moderate positive relationship; passengers who paid more had a somewhat higher survival rate.
python df[['Age','Fare','Survived']].corr() # Pearson by default
🧠
Correlation ≠ Causation. Negative values carry the same strength scale, just the opposite direction.

Outlier Detection
Unusual values that can distort means, models, and conclusions (see Decision Trees for "which method to use")
📦 IQR Method MOST COMMON — FOR SKEWED DATA
Definition

Flags any point that falls far outside the middle 50% of the data. Works well even when data is skewed.

Lower Bound = Q1 − 1.5×IQR   |   Upper Bound = Q3 + 1.5×IQR
python Q1 = df['Fare'].quantile(0.25) Q3 = df['Fare'].quantile(0.75) IQR = Q3 - Q1 lower = Q1 - 1.5 * IQR upper = Q3 + 1.5 * IQR outliers = df[(df['Fare'] < lower) | (df['Fare'] > upper)] print(f"Number of Fare outliers: {len(outliers)}")
📍 Z-Score Method FOR ROUGHLY NORMAL DATA
Definition

Flags any point more than a set number of standard deviations from the mean. Best used only on roughly normal data — skewed data will falsely flag too many/few points.

Outlier if |z| > 3
python from scipy.stats import zscore df['age_z'] = zscore(df['Age'].dropna()) outliers = df[df['age_z'].abs() > 3]
⚠️
Don't use Z-score on skewed columns like Fare — its mean and std dev are already distorted by outliers. Use IQR instead.
🧭 What To Do With an Outlier Once Found DECISION
  • Impossible value (e.g. Age = 300) → remove, it's a data-entry error
  • Genuine business value (e.g. a CEO's salary, a luxury ticket price) → keep it
  • Unsure → consult domain knowledge before deciding
📌
Descriptive statistics helps you identify outliers — it does not automatically remove them. Never remove an outlier without a business reason.

Probability

Probability is not only for inferential statistics — it also explains the "shape" concepts in Descriptive Stats (like the Normal distribution behind skewness/kurtosis) and it's the engine behind every p-value in Inferential Stats. Learn it once, use it everywhere.

🎲 Basics 🗂 Event Types 🔗 Conditional ⚡ Bayes 📊 Expected Value 🔔 Distributions 📋 Cheat Sheet
💡
Why probability sits between Descriptive and Inferential: Descriptive stats describes the shape you see (e.g. Fare is skewed). Probability explains what "shape" theoretically means (e.g. what a skewed distribution looks like mathematically). Inferential stats then uses probability to decide if a pattern is real or random chance (p-values).
1
What is Probability?
The language every statistical concept speaks
🎲 Basic Probability CONCEPT
Definition

Probability answers: how likely is something to happen? It's always a number between 0 (impossible) and 1 (certain).

P(Event) = (Favorable outcomes) ÷ (Total possible outcomes)
🚢
891 passengers total, 342 survived. P(Survived) = 342 ÷ 891 = 0.384 = 38.4%. Randomly pick one passenger → 38.4% chance they survived.
Rules to Know
  • 0 ≤ P(A) ≤ 1 always
  • P(impossible) = 0
  • P(certain) = 1
  • Sum of all outcome probabilities = 1
DA Usage
  • Survival probability per group
  • Churn probability
  • Click probability (A/B test)
  • Defect probability
2
Types of Events
Event TypeMeaningTitanic Example
IndependentOne event doesn't affect the otherP(this passenger survives) doesn't affect P(next passenger survives)
DependentOne event changes the probability of the otherP(Survived | Female) — gender affects survival
Mutually ExclusiveCan't happen at the same timeSurvived = 1 and Survived = 0 can't both be true
ExhaustiveTogether they cover all possibilitiesSurvived + Not Survived = all passengers
3
Conditional Probability
🔗 P(A | B) CRITICAL
Definition

Probability of A given that B has already happened.

P(A | B) = P(A and B) ÷ P(B)

Read as: "Probability of A given B"

🚢
P(Survived | Female) = (females who survived) ÷ (total females) = 233 ÷ 314 = 0.742 = 74.2%. Compare to overall 38.4% — being female changed the probability dramatically.
🧠
Why this matters for DA: every time you run pd.crosstab(normalize='index'), you're calculating conditional probability.
4
Bayes' Theorem
Definition

Lets you update your belief about something when you get new evidence.

P(A | B) = [ P(B | A) × P(A) ] ÷ P(B)
Terms:
P(A) = Prior (before evidence)
P(A|B) = Posterior (after evidence)
P(B|A) = Likelihood
P(B) = Normalizing factor
Titanic: You know someone survived — what's the probability they were female?
P(Female|Survived) = P(Survived|Female)×P(Female) ÷ P(Survived) = (0.742 × 0.352) ÷ 0.384 = 0.68
📍
Where DA uses Bayes: spam filters, recommendation engines, Naive Bayes classifier, A/B test evaluation, medical diagnosis models.
5
Expected Value
Definition

The average outcome you'd expect if you ran the experiment many times.

E(X) = Σ [ x × P(x) ]
🚢
Survived with P=0.384, died with P=0.616. E(Survived) = (1×0.384)+(0×0.616) = 0.384 — equals the mean of the Survived column. For binary data, expected value IS the mean!
6
Probability Distributions
The theoretical shapes real data columns approximate
🎯
What is a distribution? For each possible value of your data, it tells you how likely that value is — a map of probability. Descriptive stats measures the shape you observe (skew, kurtosis); a distribution is the theoretical model that shape is compared against.
🔔 Normal Distribution (Gaussian) MOST IMPORTANT
When
  • Continuous data
  • Symmetric around mean
  • Most values cluster in center
Where (DA)
  • Checking if Age is normal
  • Before running T-test
  • Outlier detection (3σ rule)
Why
  • Most statistical tests assume it
  • Central Limit Theorem relies on it
  • Standardization (z-score) built on it
How to Identify
  • Bell-shaped histogram
  • Skewness ≈ 0
  • Mean ≈ Median ≈ Mode
The Empirical Rule — 68% within 1σ, 95% within 2σ, 99.7% within 3σ (applies only to normal distributions)
Defined by μ (mean) and σ (std dev). Mean = Median = Mode.
🚢
Age (skew≈0.39) is approximately normal → T-test is valid for Age. Fare (skew≈4.78) is NOT normal → use Mann-Whitney U instead of T-test for Fare.
python from scipy.stats import norm mean_age = df['Age'].mean() std_age = df['Age'].std() prob = norm.cdf(40, mean_age, std_age) - norm.cdf(20, mean_age, std_age) print(f"P(20 < Age < 40) = {prob:.3f}") # ≈ 0.53
🎯 Binomial Distribution VERY COMMON IN DA
Definition

Used when each trial has exactly two outcomes: success or failure.

When
  • Fixed number of trials (n)
  • Each trial: Yes/No
  • Same probability each time
Where (DA)
  • Survived = 1 or 0
  • Clicked ad = yes/no
  • Churned = yes/no
  • A/B testing
Why
  • Models binary outcomes
  • Foundation of logistic regression
  • A/B test significance
How to Identify
  • Target column is 0/1
  • Counting successes in n trials
P(X = k) = C(n,k) × p^k × (1-p)^(n-k)

n = total trials, k = desired successes, p = probability of success each trial

python from scipy.stats import binom p = binom.pmf(k=4, n=10, p=0.384) print(f"P(exactly 4 of 10 survive) = {p:.4f}") p_atleast5 = 1 - binom.cdf(k=4, n=10, p=0.384)
🔗
Connection to DA: A/B testing ("did version B get more clicks?") uses binomial probability to check if a difference is real or chance.
⚡ Poisson Distribution GOOD TO KNOW
Definition

Used for counting events in a fixed period when events are rare and independent.

When
  • Counting events per time/space
  • Events are rare
  • Events don't affect each other
Where (DA)
  • Orders per hour
  • Support tickets per day
  • Server errors per minute
Why
  • Models frequency of rare events
  • Anomaly detection
How to Identify
  • "How many per..." questions
  • Count data (0,1,2,3...)
P(X = k) = (λ^k × e^-λ) ÷ k!    where λ = average rate

Hypothesis Testing
The backbone of every statistical test
🎓
Think of it like a courtroom: the null hypothesis (H0) is "innocent until proven guilty." You need strong evidence (a low p-value) to reject it.
⚖️ H0 and H1 FOUNDATION
H0 — Null Hypothesis

"Nothing is happening. No relationship, no difference."

  • Sex has NO effect on survival
  • Mean age of survivors = non-survivors
  • Pclass and Survival are independent
H1 — Alternate Hypothesis

"Something IS happening. A real relationship or difference exists."

  • Sex significantly affects survival
  • Survivors are significantly younger/older
  • Pclass and Survival ARE related
📉 The p-value CRITICAL
Definition

Answers: "If H0 were true, how likely is it I'd see this data (or something more extreme) just by chance?" A small p-value means "very unlikely to be random — something real is happening."

p-value = the tail area beyond your test statistic. Smaller area = more extreme = more significant.
p-valueMeaningDecision
p < 0.001Extremely strong evidence against H0✅ Reject H0 confidently
p < 0.01Very strong evidence✅ Reject H0
p < 0.05Standard threshold — significant✅ Reject H0
p > 0.05Not enough evidence❌ Fail to reject H0
⚠️
Common mistake: the p-value is NOT the probability that H0 is true. It's the probability of seeing this data IF H0 were true.
🎚️ Significance Level (α) and Confidence Level MUST KNOW

α (alpha) = your threshold for rejecting H0, set BEFORE running the test. Usually 0.05.

α = 0.05 → you accept a 5% risk of being wrong when you reject H0

Also called the false-positive rate / Type I error rate.

Confidence Level = 1 − α. If α = 0.05 → 95% confidence.

95% Confidence = 95% sure the pattern is real, not random

0.05 is standard in DA unless the domain demands higher (medical/finance often use 0.01).

❌ Type I & Type II Errors KNOW FOR INTERVIEWS
Error TypeWhat HappenedAlso CalledTitanic Example
Type I (False Positive)Rejected H0 but it was actually trueα errorConcluded Sex affects survival, but it was random luck in this sample
Type II (False Negative)Didn't reject H0 but it was actually falseβ errorConcluded Age doesn't matter, but the sample was too small to detect it

Normality Testing
Check this BEFORE any test — it decides your entire path forward
🚦
T-test and ANOVA assume your data is normally distributed. Skip this check and you'll get wrong results on skewed columns like Fare.
🔍 How to Check Normality STEP BY STEP

Method 1 — Visual: histogram (bell-shaped?) and Q-Q plot (points on a straight diagonal line?).

python sns.histplot(df['Age'], kde=True) stats.probplot(df['Age'], dist="norm", plot=plt)

Method 2 — Shapiro-Wilk Test (statistical):

Definition

A hypothesis test where H0: the data IS normally distributed, H1: it is not.

python from scipy.stats import shapiro stat, p = shapiro(df['Age']) if p > 0.05: print("✅ Normal — Use T-test / ANOVA / Pearson") else: print("❌ Not Normal — Use Mann-Whitney / Kruskal-Wallis / Spearman")
📌
Shapiro-Wilk logic is reversed: p > 0.05 → fail to reject H0 → data IS normal ✅. p < 0.05 → data is NOT normal ❌. Here you want a high p-value!

Method 3 — Skewness rule of thumb:

Skewness ValueMeaningNormal?

±0.5 to ±1Moderately skewed⚠️ Use caution
< -1 or > 1Highly skewed❌ Not normal — use non-parametric
🚢
Age skewness ≈ 0.39 → moderate/approx normal → T-test acceptable (n=891 is large). Fare skewness ≈ 4.78 → extremely skewed → always use Mann-Whitney for Fare, never T-test.

Statistical Tests
The tools you actually run — when, why, where, and how
χ² Chi-Square Test CAT vs CAT
Definition

Tests whether two categorical variables are independent or related, by comparing observed counts to the counts expected under independence.

When
  • Both variables categorical
  • Sample size ≥ 30
  • Expected freq per cell ≥ 5
Where (DA)
  • Sex vs Survived
  • Pclass vs Survived
  • Embarked vs Survived
Why
  • Tests if categories are independent
  • Validates crosstab findings
Assumptions
  • Observations independent
  • Expected cell count ≥ 5
🔬
H0: Sex and Survival are independent. H1: they are dependent.
python from scipy.stats import chi2_contingency ct = pd.crosstab(df['Sex'], df['Survived']) chi2, p, dof, expected = chi2_contingency(ct) if p < 0.05: print("✅ Significant — Sex IS related to Survival")
📊
Cramér's V — after Chi-Square, measures HOW STRONG the relationship is: V = sqrt(chi2 / (n × min(r-1, c-1))). V near 0 = weak, near 1 = strong.
📊 T-Test NUM vs 2 GROUPS (NORMAL)
Definition

Compares the means of a numerical column between two groups, testing whether the difference is real or could be random.

TypeWhen to UseTitanic Example
Independent (2-sample)2 different unrelated groupsAge of survivors vs non-survivors
PairedSame subjects measured twiceBefore/after treatment
One-sampleSample vs known valueTitanic avg age vs global 1912 avg age (30)
🔬
H0: Mean age of survivors = mean age of non-survivors. H1: they differ.
python from scipy.stats import ttest_ind survived = df[df['Survived']==1]['Age'] not_survived = df[df['Survived']==0]['Age'] t_stat, p = ttest_ind(survived, not_survived, nan_policy='omit')
⚠️
Check normality FIRST. If not normal, use Mann-Whitney U instead (always for Fare).
🔀 Mann-Whitney U Test NON-PARAMETRIC T-TEST
Definition

The non-parametric alternative to the T-test. Compares rankings/medians instead of means — robust for skewed data.

When
  • Data is NOT normal
  • Comparing 2 groups
  • Ordinal data
Where (DA)
  • Fare vs Survived (skewed!)
  • Any skewed numerical vs groups
Why
  • No normality assumption
  • Resistant to outliers
Rule of Thumb
  • Skewness > 1 → use this
python from scipy.stats import mannwhitneyu fare_s = df[df['Survived']==1]['Fare'] fare_ns = df[df['Survived']==0]['Fare'] u, p = mannwhitneyu(fare_s, fare_ns, alternative='two-sided')
📊 ANOVA (Analysis of Variance) NUM vs 3+ GROUPS
Definition

Extends the T-test to 3 or more groups — tests whether the mean differs significantly across groups.

🔑
ANOVA only tells you "at least one group differs," not which one. Follow up with a post-hoc test (Tukey HSD).
🔬
H0: mean Fare is the same across all 3 Pclasses. H1: at least one differs.
python from scipy.stats import f_oneway, kruskal from statsmodels.stats.multicomp import pairwise_tukeyhsd c1,c2,c3 = [df[df['Pclass']==i]['Fare'] for i in [1,2,3]] f_stat, p = f_oneway(c1, c2, c3) tukey = pairwise_tukeyhsd(endog=df['Fare'], groups=df['Pclass'], alpha=0.05) # Fare is skewed → non-parametric alternative: h_stat, p = kruskal(c1, c2, c3)

📏 Confidence Intervals FOR REPORTING
Definition

A p-value tells you IF something is significant. A confidence interval (CI) tells you how big the effect is and in which direction, with a range of plausible true values.

📌
"Average age of survivors is 28.4 years, 95% CI [26.8, 30.0]" — you're 95% confident the true population average lies between 26.8 and 30.0.
python from scipy import stats def confidence_interval(data, confidence=0.95): n, mean = len(data), np.mean(data) se = stats.sem(data) return mean, stats.t.interval(confidence, df=n-1, loc=mean, scale=se)
✅
If two groups' CIs don't overlap → the difference is likely significant. If they overlap → likely not significant (confirm with a T-test).

Quick-Reference Rule Tables
Mean vs Median Rule
  • Mean ≈ Median → Symmetric distribution
  • Mean > Median → Right-skewed
  • Mean < Median → Left-skewed
Standard Deviation Rule
  • Small SD → values are close together
  • Large SD → values are widely spread
Boxplot Rules
  • No points outside whiskers → no outliers
  • Points outside whiskers → possible outliers
  • Large box → high variability
  • Small box → low variability
Empirical (68-95-99.7) Rule
  • Applies only to Normal distributions
  • 68% within ±1 SD
  • 95% within ±2 SD
  • 99.7% within ±3 SD
